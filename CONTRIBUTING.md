# Contribuir

Este es un proyecto personal en desarrollo activo, pero abierto a comentarios, ideas o colaboración.

## Antes de nada

Lee [`CLAUDE.md`](CLAUDE.md) y [`docs/estado-actual.md`](docs/estado-actual.md) — explican el flujo de trabajo (Spec-Driven Development, `specs/NNN-nombre-modulo/`) y el punto exacto en el que está el proyecto. Evita reconstruir el contexto solo a partir de los commits.

## Cómo proponer un cambio

1. Abre un [issue](../../issues) describiendo el problema o la idea antes de un PR grande — este proyecto sigue spec-driven development, así que un cambio de funcionalidad normalmente necesita su propia spec en `specs/` antes de implementarse.
2. Para fixes pequeños (typos, bugs claros), un PR directo está bien.
3. Cada feature vive en su propia rama (`NNN-nombre-modulo`) y se integra con merge explícito, no fast-forward.

## Para hablar del proyecto sin pasar por GitHub

Escríbeme directamente — ver la sección de contacto en el [README](README.md#contacto).
